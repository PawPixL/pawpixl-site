Festering Desire

A 4-star sword. Base ATK 510 at Lv. 90, with 45.9% Energy Recharge.

Passive: Undying Admiration

Increases Elemental Skill DMG by 16% and Elemental Skill CRIT Rate by 6%.

At each refinement

  • Refinement 1: 16% / 6%
  • Refinement 2: 20% / 7.5%
  • Refinement 3: 24% / 9%
  • Refinement 4: 28% / 10.5%
  • Refinement 5: 32% / 12%

How to get it

Event: Unreconciled Stars (v1.2)

Description

A creepy straight sword that almost seems to yearn for life. It drips with a shriveling venom that could even corrupt a mighty dragon.

Added in version 1.2.
