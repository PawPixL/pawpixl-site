Oathsworn Eye

A 4-star catalyst. Base ATK 565 at Lv. 90, with 27.6% ATK%.

Passive: People of the Faltering Light

Increases Energy Recharge by 24% for 10s after using an Elemental Skill.

At each refinement

  • Refinement 1: 24%
  • Refinement 2: 30%
  • Refinement 3: 36%
  • Refinement 4: 42%
  • Refinement 5: 48%

How to get it

Event: Three Realms Gateway Offering event

Description

A national treasure of Byakuyakoku stored in the Dainichi Mikoshi. With the coming of the Serpent God, this item was used to notarize great oaths and wishes.

Added in version 2.5.
