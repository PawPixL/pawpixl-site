Messenger

A 3-star bow. Base ATK 448 at Lv. 90, with 31.2% CRIT DMG.

Passive: Archer's Message

Charged Attack hits on weak points deal an additional 100% ATK DMG as CRIT DMG. Can only occur once every 10s.

At each refinement

  • Refinement 1: 100%
  • Refinement 2: 125%
  • Refinement 3: 150%
  • Refinement 4: 175%
  • Refinement 5: 200%

How to get it

Free: Treasure chests

Description

A basic wooden bow. It is said to have once been used as a tool for long-distance communication.
