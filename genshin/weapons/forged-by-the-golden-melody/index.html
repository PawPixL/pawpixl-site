Forged by the Golden Melody

A 4-star claymore. Base ATK 510 at Lv. 90, with 27.6% CRIT Rate.

Passive: Day and Night in Counterpoint

Every 10s, the equipping character plays a "Harmonic Movement" of the corresponding type for a boost in the following order: +18% ATK > +120 Elemental Mastery > +28% Stellar Glimmer reaction DMG. Each instance of Harmonic Movement lasts 10s. This effect can trigger even when the equipping character is not on the field. Triggering a Stellar Glimmer reaction will also grant an additional 12-second instance of "Harmonic Movement: Contrapuntal" with the same effects as the Harmonic Movement active when Stellar Glimmer is triggered. This effect stacks with the original Harmonic Movement effect, and can trigger once every 12s.

At each refinement

  • Refinement 1: +18% / +120 / +28%
  • Refinement 2: +22.5% / +150 / +35%
  • Refinement 3: +27% / +180 / +42%
  • Refinement 4: +31.5% / +210 / +49%
  • Refinement 5: +36% / +240 / +56%

How to get it

Battle Pass: Gnostic Hymn weapon chest

Description

A greatsword decorated in gold. Legend has it that it was the favored weapon of a certain exalted Harmost back in the distant past.
