Waveriding Whirl

A 4-star catalyst. Base ATK 454 at Lv. 90, with 61.3% Energy Recharge.

Passive: Fangs Flying To and Fro

Decreases Swimming Stamina consumption by 15%. In addition, for 10s after using an Elemental Skill, Max HP is increased by 20%. For every Hydro Elemental Type character in the party, Max HP is increased by another 12%, and the maximum increase that can be achieved in this way is 24%. Can be triggered once every 15s.

At each refinement

  • Refinement 1: 20% / 12% / 24%
  • Refinement 2: 25% / 15% / 30%
  • Refinement 3: 30% / 18% / 36%
  • Refinement 4: 35% / 21% / 42%
  • Refinement 5: 40% / 24% / 48%

How to get it

Gacha: Event wish (v6.7)

Description

A boomerang made from the fangs of a giant sea serpent. It was a rare weapon indeed that the giant Tupac would call "trusty."

Added in version 5.2.
