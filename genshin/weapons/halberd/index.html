Halberd

A 3-star polearm. Base ATK 448 at Lv. 90, with 23.5% ATK%.

Passive: Heavy

Normal Attacks deal an additional 160% ATK as DMG. This effect can only occur once every 10s.

At each refinement

  • Refinement 1: 160%
  • Refinement 2: 200%
  • Refinement 3: 240%
  • Refinement 4: 280%
  • Refinement 5: 320%

How to get it

Free: Treasure chests

Description

A polearm with an axe blade mounted on top that can deal quite a lot of damage. It's favored by the Millelith officers.

Added in version 1.0.
