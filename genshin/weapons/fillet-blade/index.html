Fillet Blade

A 3-star sword. Base ATK 401 at Lv. 90, with 35.2% ATK%.

Passive: Gash

On hit, has a 50% chance to deal 240% ATK DMG to a single opponent. Can only occur once every 15s.

At each refinement

  • Refinement 1: 240% / 15
  • Refinement 2: 280% / 14
  • Refinement 3: 320% / 13
  • Refinement 4: 360% / 12
  • Refinement 5: 400% / 11

How to get it

Free: Treasure chests

Description

A sharp filleting knife. The blade is long, thin, and incredibly sharp.
