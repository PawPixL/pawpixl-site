Blackmarrow Lantern

A 4-star catalyst. Base ATK 454 at Lv. 90, with 221 Elemental Mastery.

Passive: Token of Covenant

Bloom DMG is increased by 48%, and Lunar-Bloom DMG is increased by 12%. Moonsign: Ascendant Gleam: Lunar-Bloom DMG is increased by an additional 12%.

At each refinement

  • Refinement 1: 48% / 12% / 12%
  • Refinement 2: 60% / 15% / 15%
  • Refinement 3: 72% / 18% / 18%
  • Refinement 4: 84% / 21% / 21%
  • Refinement 5: 96% / 24% / 24%

How to get it

Craft: Forge (Nod-Krai)

Description

A lantern that emits a faint, ghostly glow, contained by a midnight-black alloy that resembles interlocking bones. It is said to have once been revered as a precious treasure by a certain secret organization.

Added in version 6.0.
