Prospector's Shovel

A 4-star polearm. Base ATK 510 at Lv. 90, with 41.4% ATK%.

Passive: Swift and Sure

Electro-Charged DMG is increased by 48%, and Lunar-Charged DMG is increased by 12%. Moonsign: Ascendant Gleam: Lunar-Charged DMG is increased by an additional 12%.

  • Refinement 2: 60% / 15% / 15%
  • Refinement 3: 72% / 18% / 18%
  • Refinement 4: 84% / 21% / 21%
  • Refinement 5: 96% / 24% / 24%

Description
